Registration works roughly the same on every exchange; the differences are in the interface. What you need: an email or phone number you have permanent access to. This is not a formality: the exchange regularly confirms the account is yours by email or SMS code. Losing access to the email or number means trouble accessing the account.

## Registration

1. Open the registration page via a verified link.
2. Enter an email (or number) and a strong password.
3. Confirm the email or number with a six-digit code from the message or SMS.

The account is created.

## What 2FA is and why

**2FA (two-factor authentication)** is an extra layer of protection. On login and on operations the exchange asks not only for the password but for a code from a separate app on your phone. A password can be stolen, intercepted or guessed; the app code changes every 30 seconds and is never sent over the network. Enable 2FA on every venue that offers it.

## Setting it up

1. Open account settings, the Security section.
2. Choose to link an authenticator app. The exchange sends a confirmation code to your email.
3. Scan the shown QR code with the authenticator app. If the camera fails, a 16-character key is shown beside it — enter it manually, the result is the same.
4. Enter the current code from the app on the site. The code lasts 30 seconds, with a timer beside it.

## Save the key separately

The 16-character key is the only way to restore access if the phone with the app is lost. Save it separately, preferably on paper. Without it, recovery becomes a long exchange with support and is sometimes impossible.

## What to remember

- Until the key is saved separately, deleting the app means losing access.
- The 2FA code is asked on every login and on every withdrawal.
- Disabling 2FA needs both the app code and the email code — that is protection, not an obstacle.
