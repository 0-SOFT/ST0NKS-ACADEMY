# ST0NKS Academy

Контент учебника и блога [ST0NKS](https://scanyourmommy.duckdns.org) — сервиса поиска и анализа
арбитражных связок на крипторынке.

В этом репозитории **только контент**: тексты, изображения, файл порядка разделов. Кода продукта
здесь нет и не будет.

## Зачем отдельный репозиторий

Текст правится и выкладывается **без выкладки кода**. Опечатка в статье не должна требовать сборки
и развёртывания сервиса, а история правок текста не должна тонуть в истории правок кода.

## Устройство

```
content/
  en/academy/<раздел>/<страница>.md    учебник, английский
  ru/academy/<раздел>/<страница>.md    учебник, русский
  en/blog/<статья>.md                  блог, английский
  ru/blog/<статья>.md                  блог, русский
media/<хеш-содержимого>.<расширение>   изображения и схемы
sections.json                          порядок и названия разделов учебника, оба языка
```

**Имя файла изображения — хеш его содержимого.** Одна и та же картинка не хранится дважды, а замена
картинки не требует чистки кэша: новое содержимое даёт новое имя.

## Служебный заголовок страницы

Каждый файл начинается с заголовка. Без него страница не принимается.

```yaml
---
title: Порог безубыточности
description: Почему спред в 0,3 % может быть убыточным
slug: breakeven
pair: breakeven          # ключ связи с версией на втором языке
section: mechanics       # раздел учебника; для блога не нужен
date: 2026-09-03
topics: [комиссии, риск]
---
```

Поле `pair` связывает английскую и русскую версии. **Страница существует на обоих языках или не
существует вовсе**: половина учебника на чужом языке хуже, чем честное отсутствие статьи.

## Правила содержания

1. **Тексты свои.** Не пересказ чужих статей, а собственное изложение фактов. Факты — порог
   безубыточности, механика фандинга, устройство стакана — не охраняются авторским правом;
   охраняется изложение. Поэтому изложение — своё, с собственной структурой.
2. **Оба языка — самостоятельные тексты**, а не текст и его перевод. Русская и английская версии
   объясняют одно и то же, но каждая написана для своего читателя.
3. **Все изображения свои**: снимки нашего сканера и страницы связки, наши схемы. Ни одного чужого
   изображения.
4. **Числа — из наших собственных замеров**, с датой замера рядом.
5. **Эмодзи в оформлении не используются.**
6. Чужой сервис можно упомянуть как факт о рынке. Нельзя — как источник, из которого переписано.

## Как это попадает на сайт

Сервис забирает содержимое этого репозитория, проверяет целостность (все внутренние ссылки ведут в
существующие страницы, все изображения на месте, у каждой страницы есть пара на втором языке) и
только после этого применяет **целиком и разом**. Не прошло проверку — на сайте остаётся предыдущая
версия, а не половина новой.
