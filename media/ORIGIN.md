# Происхождение медиафайлов

Каждый файл в `media/` перечислен здесь с ответом на один вопрос: **откуда он взялся**. Чужих
изображений в этом репозитории нет и быть не должно — не из осторожности, а потому что учебник
про наш инструмент иллюстрируется нашим инструментом.

Имя файла — первые шестнадцать знаков SHA-256 его содержимого. Поэтому имя нельзя подделать
незаметно: изменённый файл получает другое имя, а адрес со старым именем перестаёт существовать.
Это же свойство позволяет кэшировать файлы навсегда.

| Файл | Что на нём | Как получен | SHA-256 |
|---|---|---|---|
| `scanner-shelf-b0a5be2402f8fa09.png` | витрина сканера ST0NKS, сортировка по торгуемости, русская версия | снимок окна 1280x900 нашей страницы `/ru/scaner` на боевом сервере, 3 сентября 2026 года | `b0a5be2402f8fa09ba3c2a3dd8a79c4110be6bdf49f35495aae5fd1956b9260b` |

## Правила для новых файлов

1. **Только наше.** Снимки наших страниц, наши схемы. Ни одного чужого изображения, включая
   «нейтральные» иллюстрации из общедоступных подборок.
2. **Имя — хеш содержимого**, первые шестнадцать знаков, расширение по типу.
3. **Строка в этой таблице обязательна** и заполняется в тот же коммит. Файл без строки — файл
   неизвестного происхождения, а «потом впишу» означает «никогда».
4. **Описание в статье содержательное.** Человек, который изображение не видит, должен узнать из
   подписи то же самое: что показано, какие числа, когда сделан замер.
